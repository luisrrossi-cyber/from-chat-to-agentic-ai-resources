# First Artifact — Acceptance Checklist

Use this checklist for one deliverable. Adapt it to the actual task.

- [ ] The artifact exists in the agreed location.
- [ ] It matches the requested audience, purpose, and scope.
- [ ] Required sections or behaviors are present.
- [ ] Claims trace to approved sources or are marked for verification.
- [ ] Assumptions and missing information are visible.
- [ ] The file opens or runs in the intended environment.
- [ ] The listed checks were actually performed and recorded.
- [ ] No credentials, secrets, or unnecessary personal data were added.
- [ ] Changes outside the agreed scope are explained or reverted.
- [ ] Current state and next task are updated.
- [ ] Owner approval is recorded where required.

Mark each item PASS, FAIL, or NOT VERIFIED in the project record. Do not treat NOT VERIFIED as a pass.
