# AI Project Playbook — Starter Kit

Use these templates to organize one project that continues beyond a single chat. They work as plain text files in a local project folder or in a private repository you control.

## Start here

1. Copy this folder into your own project workspace and rename it for your project.
2. Complete `PROJECT_BRIEF_TEMPLATE.md`.
3. Rename the other templates to `CURRENT_STATE.md`, `DECISIONS.md`, `EVIDENCE.md`, and `HANDOFF.md`.
4. Keep `AGENTS.md` as project working rules; add tool-specific instruction files only if your chosen assistant reads them.
5. Work through `ACCEPTANCE_CHECKLIST.md` before treating the first artifact as complete.

Keep credentials, access tokens, passwords, recovery codes, and unnecessary personal or customer data out of these files. Do not store your own project files in this public download repository. If you copy them into GitHub, use a private repository for sensitive work and verify its access settings. Start with read access or manual file sharing; give tools write access only when needed.

These templates are a starting point. Remove sections that do not serve your project and add project-specific instructions only after you understand the workflow.
