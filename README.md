# From Chat to Agentic AI — Companion Starter Kit

> **Don't Just Chat With AI. Build With It.**

This public repository contains the editable project templates that accompany *From Chat to Agentic AI*. It does not contain the book manuscript.

## Download

**[Download the Starter Kit as a ZIP](https://github.com/luisrrossi-cyber/from-chat-to-agentic-ai-resources/archive/refs/heads/main.zip).** You can also select **Code → Download ZIP** on this page. The archive includes this guide and the files in `starter-kit/`.

## What is included

| File | Use |
|---|---|
| `PROJECT_BRIEF_TEMPLATE.md` | Define the outcome, audience, scope, evidence, and approval boundaries. |
| `AGENTS.md` | Record project working instructions for AI tools that read this file. |
| `CURRENT_STATE_TEMPLATE.md` | Track confirmed progress, open items, and the next bounded task. |
| `DECISIONS_TEMPLATE.md` | Preserve durable choices and the reason for each one. |
| `EVIDENCE_TEMPLATE.md` | Record sources and checks that were actually performed. |
| `HANDOFF_TEMPLATE.md` | Help another session or assistant continue from the current state. |
| `ACCEPTANCE_CHECKLIST.md` | Review one deliverable before treating it as complete. |\n| `RECOVERY_CHECKLIST.md` | Restore project work safely after account, device, or session loss. |\n| `tools/check_markdown_links.py` | Optionally check relative Markdown file links and heading anchors locally. |

The folder also includes its own `README.md` with setup steps. The link checker uses only Python's standard library; it does not check external URLs or verify factual content.

## Start safely

1. Download and extract the ZIP.
2. Copy the `starter-kit/` folder into a workspace or repository you control.
3. Follow its README and rename the templates for your project.
4. Keep your personal work, credentials, customer data, and private files out of this public repository. Use a private workspace when the work needs restricted access.

These files do not give an AI tool access to your repository or create automatic memory. Connect tools deliberately, check what they can read or change, and review their work.
